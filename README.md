
# ComicLens Translator

A desktop application for real-time multilingual
comic and manga translation.

## Features

- Live screen capture
- OCR text recognition
- Multilingual translation
- English and Indonesian translation
- Floating translation overlay

## Technology

- Python 3.11
- PySide6
- Tesseract OCR
- OpenCV
- MSS
- Deep Translator

## Project Status

Currently under development.
